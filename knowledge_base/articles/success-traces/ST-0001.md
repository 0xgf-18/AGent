## Experiment Sequence

### Step 1
**Observation:** Fingerprint reports 1 dex + 16 native libs + 360 jiagu assets
**Action:** Extract classes.dex from the APK zip
**Tool:** TR-0011 (version: `stdlib zipfile`)
**Host/Device:** host
**Command:** `python -c "import zipfile; z=zipfile.ZipFile('myprotectorproject.apk'); open('classes.dex','wb').write(z.read('classes.dex'))"`
**Duration:** 1s
**Result:** 44668 bytes written
**Success Indicator Observed:** shell-size < 100 KB
**Artifacts Produced:** ART-0001
### Step 2
**Observation:** Shell dex extracted
**Action:** Validate DEX header: magic, file_size, adler32, sha1, string/type ids
**Tool:** TR-0012 (version: `verify_result.py`)
**Host/Device:** host
**Command:** `python .kb/scripts/verify_result.py parser --dex classes.dex`
**Duration:** 1s
**Result:** PASS - magic/size/adler32/sha1 ok; 639 strings, 87 types
**Success Indicator Observed:** dex-valid, string_ids>0
**Artifacts Produced:** ART-0001
### Step 3
**Observation:** Header valid; need to know WHICH classes are in the shell
**Action:** Content probes for loader class and app class
**Tool:** TR-0009 (version: `verify_result.py`)
**Host/Device:** host
**Command:** `python .kb/scripts/verify_result.py content --file myprotectorproject.apk --class com.qihoo.util.VM && python .kb/scripts/verify_result.py content --file myprotectorproject.apk --class pokemon.dex.guard.Application`
**Duration:** 2s
**Result:** com.qihoo.util.VM PASS; pokemon.dex.guard.Application FAIL (descriptor not in any dex)
**Success Indicator Observed:** qihoo-shell-classes, app-classes-absent
**Artifacts Produced:** ART-0001
### Step 4
**Observation:** Content confirmed packed; verify packaging + stability
**Action:** Run gate categories: STRUCTURAL, DOWNSTREAM, REPRODUCIBILITY and combine all 6 checks
**Tool:** TR-0007 (version: `verify_result.py gate`)
**Host/Device:** host
**Command:** `python .kb/scripts/verify_result.py gate r1.json r2.json r3.json r4.json r5.json r6.json`
**Duration:** 25s
**Result:** VERIFIED_SUCCESS - 5 categories passed, gate exit 0
**Success Indicator Observed:** gate=VERIFIED_SUCCESS
**Artifacts Produced:** ART-0001
