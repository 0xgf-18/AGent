## Learning Extracted
- **What worked:** verify_result.py gate across 5 categories; DEX adler32/sha1 header validation proves integrity cheaply; class-descriptor scans identify shell vs app classes without decompilation
- **What didn't work:** assuming app classes live in classes.dex - pokemon.dex.guard.Application is absent (packed)
- **Environment sensitivity:** none - purely host-side checks, would also pass on physical-noroot-001
- **Tool version sensitivity:** build-tools 35.0.0 apksigner prints 'SHA-256 digest:' (older versions print 'SHA-256:')
- **New indicators discovered:** com.qihoo.* shell classes, 44.6 KB stub dex, ProtectV1/V2/V3.zip assets
- **Refined applicability for technique:** T-0008 works as pre-unpack baseline; CONTENT checks must target shell package (com.qihoo) for packed APKs, app package only after unpack
